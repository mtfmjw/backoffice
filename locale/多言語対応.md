# 多言語対応

## GNU gettextのインストール

```batch
winget install mlocati.GetText
```

## ソースより翻訳対象となる文字列を抽出

- 日本語版のlocale/ja/LC_MESSAGES/django.poファイルを作成する

```batch
python manage.py makemessages -l ja
```

- poファイルを編集して日本語に編訳する
- poファイルをコンパイルする

```batch
python manage.py compilemessages -l ja
```

- サーバーを再起動したら編集されたメッセージが日本語で表示される
